# Selecting the right proof asset for Upwork

| Job requirement | Best 20–40 second proof clip | One careful promise |
|---|---|---|
| GoHighLevel CRM workflows | New lead, contact upsert and pipeline stage | Will map actual GHL location IDs, duplicate rules, pipeline and fields after access |
| n8n / webhook automation | Webhook intake → status branch / HTTP trace | Will import and version-test the JSON in the client's authorized workspace |
| Appointment systems | Conflict check, booking result, repeated event | Will check native calendar availability/notice windows under the target account |
| Automation troubleshooting | Simulated 429/401 and notification failure | Will instrument provider errors and test recovery with the client's real APIs |
| AI-assisted lead qualification | Deterministic routing + optional local Ollama advisory | Will confirm permitted model, evaluation examples and human-review limits |

Never imply GHL account access if you used only the mock connector. Send a relevant clip and one personalized engineering question. No mass-produced generic proposals.
